# README

## 1. Molecular Dynamics Simulation

A 2D molecular dynamics simulation that models interacting particles and visualizes their motion over time.

**Requirements:**
- VPython
- Matplotlib

**How to run:**

```bash
python molecular_dynamics.py
```

The program allows you to tune various simulation parameters at startup, including the number of particles, box size, target temperature, and visualization settings. To use all default values, simply press Enter at each prompt.

## 2. Threes Emulator

A Python implementation of a Threes-inspired number-merging game, featuring both human and AI gameplay.

**Requirements:**
- Matplotlib

**How to run:**

```bash
python threes_emulator_v3.py
```

**How to play:**
- Use the arrow keys (↑, ↓, ←, →) to move tiles when playing manually.
- The game also supports computer-controlled gameplay using the built-in AI.
